## How to use this file

- This is the quick-recall source: grep / Ctrl-F this file instead of re-reading the full catalogue.
- **By place:** search the broad area in `Region(s)` (e.g. `Fiordland`) and the specific track/feature in `Locations` (e.g. `Routeburn`, `Cascade Saddle`).
- **By activity / audience:** cells can hold multiple values separated by `;` so search for the term (e.g. `Sea kayaking`, `Families`, `Solo`).
- **Flags:** `FLAG:` in Notes = a tag that was uncertain from the description alone. `TW` = content warning in that episode.
